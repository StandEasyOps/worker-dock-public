# Security policy

## Supported versions

Security fixes go to the latest GitHub Release only.

| Version | Supported |
| --- | --- |
| Latest release | Yes |
| Older releases | No |

This repository has no GitHub Release yet. Until the first one, the supported line is `main`.

## Reporting a vulnerability

Report vulnerabilities through GitHub private vulnerability reporting:

https://github.com/StandEasyOps/worker-dock-public/security/advisories/new

Do not open a public issue or pull request for a security report.

Maintainers will acknowledge the report and coordinate a fix before public disclosure.
